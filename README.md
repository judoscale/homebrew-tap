# Judoscale Homebrew tap

Homebrew formulae for [Judoscale](https://judoscale.com).

```sh
brew install judoscale/tap/judo
```

This installs the [Judoscale CLI](https://github.com/judoscale/judoscale-cli), `judo`, plus a `judoscale` alias. The formula is updated automatically on each CLI release; please report issues on the CLI repo.
